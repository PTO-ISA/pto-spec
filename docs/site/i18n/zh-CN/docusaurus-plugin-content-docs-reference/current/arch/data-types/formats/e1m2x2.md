## 用途与范围

`E1M2X2` 是已分配的 PTO 数值格式，其数值是以每两个四位 lane 打包进一个八位载体的形式存储；本单元拥有它的描述符、有限值分解、值分类和有符号零编码。

该所有者一次只暴露一个 lane，通过 `value[3:0]` 读取；而按索引读取 lane 的调用方可以使用 `PackedTileElementFromWord` 选出打包四位载体中的任一四位组。

设计要点：该记录把载体宽度与逻辑 lane 宽度分开，因此打包类型在一个载体中报告两个 lane，而单 lane 类型在其载体中只报告自己的 lane 宽度。

<!-- PTO-READER-BLOCK: arch-format-e1m2x2-concepts role=concepts-state -->
## 载体与字段

描述符使用 `8` 位载体、`4` 位逻辑 lane，并且每个载体包含 `2` 个 lane。

lane 的符号位位于 `3`，有 `0` 个指数位，`3` 个尾数位位于 `2:0`，`exponent_bias_available` 设为 false，指数偏置为 `0`。

描述符把 `required_low_zero_bits` 和 `required_high_zero_bits` 都设为 `0`，因此每个八位载体容纳两个已定义的 lane 编码。

<!-- PTO-READER-BLOCK: arch-format-e1m2x2-rules role=rules-interactions -->
## 分解与分类

`E1M2X2FiniteDecomposition` 返回可用性、符号、整数有效数和二进制指数，使精确值为 `(-1)^sign * UInt(significand) * 2^exponent`；每个非零 lane 都以固定指数 `-2` 分解出其三位量值。

`ClassifyE1M2X2` 把该 lane 归入零类别或带符号的正规数类别；该格式没有无穷大、没有 NaN，也没有次正规数编码，因此每个非零 lane 都是带符号的正规数。

三位量值为零的 lane 选择带符号零，其余每个 lane 都是带符号的正规数，没有可选择的指数字段。

<!-- PTO-READER-BLOCK: arch-format-e1m2x2-boundaries role=boundaries -->
## 边界与确切编码

设计要点：没有指数字段时每个 lane 的比例因子都是 `2^-2`，因此该格式以动态范围换取相邻值之间均匀的步长。

lane `0x0` 是正零，lane `0x8` 是负零；该格式没有无穷大和 NaN lane。

设计要点：`0x00` 与负编码是同一量值的两个独立编码，因此保留符号位的调用方仍能分辨结果来自哪一个，即使二者都与零相等。

按函数顺序阅读本页：先从描述符取得字段位置，在需要值类别时调用分类函数，并且只在编码有效性通过之后才调用分解函数。

## 非规范阅读示例

本例说明当前的 ASL 归属单元，不替代规范操作。

lane `0x1` 分解为有效数 `1` 和指数 `-2`，即 `0.25`；lane `0x7` 分解为有效数 `7` 和指数 `-2`，即 `1.75`。

读取载体时必须知道 lane 的位置，因为分解函数接收整个 `Word`，却只读取低四位。
