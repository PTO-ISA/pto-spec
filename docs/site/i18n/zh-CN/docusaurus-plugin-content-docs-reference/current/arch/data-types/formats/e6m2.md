## 用途与范围

E6M2 是一种无符号八位 PTO 缩放格式。本页帮助读者把原始字段、精确有限值和值分类联系起来；ASL 所有者仍是确切定义，并同时提供 HiF4 缩放字中 E6M2 字段使用的解码器。

<!-- PTO-READER-BLOCK: arch-format-e6m2-concepts role=concepts-state -->
## 载体与字段

描述符使用 `8` 位载体、`8` 位逻辑 lane，并且每个载体包含 `1` 个 lane。位 `7:2` 构成偏置为 `48` 的六位指数，位 `1:0` 构成两位尾数，有限值有效数包含隐藏前导一；该格式没有符号位。

载体中除指数和尾数字段以外，没有额外的约束位。

<!-- PTO-READER-BLOCK: arch-format-e6m2-rules role=rules-interactions -->
## 精确值与分类

对于编码 `0x00` 至 `0xfe`，`E6M2FiniteValue` 返回 `(4 + fraction) / 4 * 2^(exponent - 48)`。对应的有限值分解为正值，整数有效数为 `4 + fraction`，二进制指数为 `exponent - 50`。

该有限范围中的每个编码都是正正规数。编码 `0xff` 是静默 NaN，且没有有限值分解；本格式不编码零、带符号零、次正规数、无穷大或信号 NaN。

<!-- PTO-READER-BLOCK: arch-format-e6m2-boundaries role=boundaries -->
## 边界与确切编码

`0x00` 是最小有限编码，表示 `2^-48`；`0xfe` 是最大有限编码，表示 `1.5 * 2^15`。`0xff` 既是唯一的静默 NaN 编码，也是所有者返回的规范 NaN。

有限值求值前会排除全 1 编码，而分类函数独立地把它识别为静默 NaN。
