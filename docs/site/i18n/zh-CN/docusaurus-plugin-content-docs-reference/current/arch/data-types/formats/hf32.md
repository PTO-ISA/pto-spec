## 用途与范围

HF32 是 PTO 已分配的数值格式。本页帮助读者把载体布局、有限值分解和值分类联系起来；确切契约仍由 ASL 所有者中的 `HF32NumericFormatDescriptor`、`HF32FiniteDecomposition` 和 `ClassifyHF32` 定义。

<!-- PTO-READER-BLOCK: arch-format-hf32-concepts role=concepts-state -->
## 载体与字段

描述符使用 `32` 位载体、`32` 位逻辑 lane，并且每个载体包含 `1` 个 lane。lane 的符号位位于 `31`，具有 `8` 个指数位、`11` 个尾数位，指数偏置为 `127`。

`11:0` 位必须为零。11 个已存储尾数位占据 `22:12`；若低位非零，载体会在有限值分解前被判为无效。

<!-- PTO-READER-BLOCK: arch-format-hf32-rules role=rules-interactions -->
## 分解与分类

`HF32FiniteDecomposition` 先报告有限值分解是否可用；可用时返回符号、整数有效数和二进制指数。`ClassifyHF32` 则独立地把原始 lane 归入该格式所支持的零、次正规数、正规数、无穷大或 NaN 类别。

在有效载体中，它具有带符号零、次正规数、无穷大、静默 NaN 和信号 NaN。全 1 指数不提供有限值分解。

<!-- PTO-READER-BLOCK: arch-format-hf32-boundaries role=boundaries -->
## 边界与确切编码

`0x00000000` 和 `0x80000000` 分别是正零与负零；`0x7fc00000` 是规范静默 NaN。

有限值分解函数在返回的元组中报告可用性；值分类是另一个函数的独立结果。
