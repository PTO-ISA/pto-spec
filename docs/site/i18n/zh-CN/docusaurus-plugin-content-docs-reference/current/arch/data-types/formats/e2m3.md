## 用途与范围

`E2M3` 是已分配的 PTO 数值格式，其数值占据 `8` 位载体中的六位 lane；本单元拥有它的描述符、编码有效性、有限值分解、值分类和有符号零编码。

两位指数和三位尾数在更窄的范围内给出比 `E3M2` 更细的值网格。

设计要点：该记录把载体宽度与逻辑 lane 宽度分开，因此打包类型在一个载体中报告两个 lane，而单 lane 类型在其载体中只报告自己的 lane 宽度。

<!-- PTO-READER-BLOCK: arch-format-e2m3-concepts role=concepts-state -->
## 载体与字段

描述符使用 `8` 位载体、`6` 位逻辑 lane，并且每个载体包含 `1` 个 lane。

lane 的符号位位于 `5`，`2` 个指数位位于 `4:3`，`3` 个尾数位位于 `2:0`，指数偏置为 `1`；载体的 `7:6` 位被约束为零。

描述符把 `required_high_zero_bits` 设为 `2`，因此载体中只有低六位属于该数值。

<!-- PTO-READER-BLOCK: arch-format-e2m3-rules role=rules-interactions -->
## 分解与分类

`E2M3EncodingValid` 报告载体 `7:6` 位是否都为零；`E2M3FiniteDecomposition` 先拒绝约束位不为零的载体，然后返回可用性、符号、整数有效数和二进制指数，使精确值为 `(-1)^sign * UInt(significand) * 2^exponent`。

`ClassifyE2M3` 把原始 lane 归入零、次正规数或正规数类别；该格式没有无穷大和 NaN 编码，因此每个六位 lane 都表示有限值。

指数字段为零且尾数非零时选择次正规数形式，且每个非零 lane 都分类为带符号的有限值。

<!-- PTO-READER-BLOCK: arch-format-e2m3-boundaries role=boundaries -->
## 边界与确切编码

设计要点：两位指数下，分解对指数字段 `1` 返回正规数指数 `-3`，对 `2` 返回 `-2`，对 `3` 返回 `-1`，因此该格式属于小动态范围类型，其最细步长在范围下端为 `1 * 2^-3`，在上端为 `1 * 2^-1`。

`0x01` 是最小正次正规数，表示 `1 * 2^-3`；`0x08` 是第一个正规格化数，表示 `8 * 2^-3`，即 `1 * 2^0`。

设计要点：`0x00` 与负编码是同一量值的两个独立编码，因此保留符号位的调用方仍能分辨结果来自哪一个，即使二者都与零相等。

按函数顺序阅读本页：先从描述符取得字段位置，在需要值类别时调用分类函数，在需要精确有效数与指数时调用分解函数。

## 非规范阅读示例

本例说明当前的 ASL 归属单元，不替代规范操作。

`0x1f` 是最大有限值，分解为有效数 `15` 和指数 `-1`，即 `7.5`。

`0x00` 和 `0x20` 分别是正零与负零编码，`0x80` 不是合法的 `E2M3` 编码，因为 `7` 位被置位。
