## 用途与范围

E2M3 是 PTO 已分配的数值格式。本页帮助读者把载体布局、有限值分解和值分类联系起来；确切契约仍由 ASL 所有者中的 `E2M3NumericFormatDescriptor`、`E2M3FiniteDecomposition` 和 `ClassifyE2M3` 定义。

<!-- PTO-READER-BLOCK: arch-format-e2m3-concepts role=concepts-state -->
## 载体与字段

描述符使用 `8` 位载体、`6` 位逻辑 lane，并且每个载体包含 `1` 个 lane。lane 的符号位位于 `5`，具有 `2` 个指数位、`3` 个尾数位，指数偏置为 `1`。

8 位载体的 `7:6` 位必须为零；6 位数值占据 `5:0` 位。

<!-- PTO-READER-BLOCK: arch-format-e2m3-rules role=rules-interactions -->
## 分解与分类

`E2M3FiniteDecomposition` 先报告有限值分解是否可用；可用时返回符号、整数有效数和二进制指数。`ClassifyE2M3` 则独立地把原始 lane 归入该格式所支持的零、次正规数、正规数、无穷大或 NaN 类别。

它具有带符号零和次正规数，但没有无穷大或 NaN 类别。若任一受约束高位为 1，编码有效性函数和有限值分解函数都会拒绝该载体。

<!-- PTO-READER-BLOCK: arch-format-e2m3-boundaries role=boundaries -->
## 边界与确切编码

编码 `0x00` 和 `0x20` 分别表示正零与负零。

有限值分解函数在返回的元组中报告可用性；值分类是另一个函数的独立结果。

pure func E2M3FiniteDecomposition(value: bits(8))
    => (boolean, boolean, Word, integer {-1074..1023})
begin
    if value[7:6] != Zeros{2} then
        return (FALSE, FALSE, Zeros{PTO_XLEN}, 0);
    end;
    let exponent = value[4:3];
    let fraction = value[2:0];
    if exponent == Zeros{2} then
        if fraction == Zeros{3} then
            return (TRUE, value[5] == '1', Zeros{PTO_XLEN}, 0);
        else return (TRUE, value[5] == '1',
                     ZeroExtend{PTO_XLEN}(fraction), -3);
        end;
    else return (TRUE, value[5] == '1',
                 LSL(Zeros{PTO_XLEN} + 1, 3) +
                     ZeroExtend{PTO_XLEN}(fraction),

                     as integer {-1074..1023});
    end;
end;

begin
    return value[7:6] == Zeros{2};
end;

    let fraction = value[2:0];

        exponent == Zeros{2} && fraction != Zeros{3});
