## 载体与字段

描述符使用 `8` 位载体，其中包含一个 `8` 位逻辑 lane。全部 `8` 个 lane 位共同组成指数字段，指数偏置为 `127`，并且该格式没有符号位或尾数字段。

全部 8 位共同组成无符号指数字段；不存在符号位或尾数字段。

## 分解与分类

`E8M0FiniteDecomposition` 先报告有限值分解是否可用；可用时返回符号、整数有效数和二进制指数。`ClassifyE8M0` 则独立地把原始 lane 归入该格式所支持的零、次正规数、正规数、无穷大或 NaN 类别。

它没有零、带符号零、次正规数或无穷大类别。编码 `0x00` 到 `0xfe` 是正的正规 2 的幂，而 `0xff` 是静默 NaN 编码且没有有限值分解。
