## 用途与范围

E4M3 是 PTO 已分配的数值格式。本页帮助读者把载体布局、有限值分解和值分类联系起来；确切契约仍由 ASL 所有者中的 `E4M3NumericFormatDescriptor`、`E4M3FiniteDecomposition` 和 `ClassifyE4M3` 定义。

<!-- PTO-READER-BLOCK: arch-format-e4m3-concepts role=concepts-state -->
## 载体与字段

描述符使用 `8` 位载体、`8` 位逻辑 lane，并且每个载体包含 `1` 个 lane。lane 的符号位位于 `7`，具有 `4` 个指数位、`3` 个尾数位，指数偏置为 `7`。

载体中除符号、指数和尾数字段以外，没有额外的约束位。

<!-- PTO-READER-BLOCK: arch-format-e4m3-rules role=rules-interactions -->
## 分解与分类

`E4M3FiniteDecomposition` 先报告有限值分解是否可用；可用时返回符号、整数有效数和二进制指数。`ClassifyE4M3` 则独立地把原始 lane 归入该格式所支持的零、次正规数、正规数、无穷大或 NaN 类别。

它具有带符号零、次正规数和静默 NaN 类别，但没有无穷大或信号 NaN 类别。只有全 1 指数与全 1 尾数同时出现时才是非有限值。

<!-- PTO-READER-BLOCK: arch-format-e4m3-boundaries role=boundaries -->
## 边界与确切编码

`0x00` 和 `0x80` 分别是正零与负零；`0x7f` 是规范静默 NaN。

有限值分解函数在返回的元组中报告可用性；值分类是另一个函数的独立结果。
