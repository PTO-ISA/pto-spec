## 用途与范围

E5M2 是 PTO 已分配的数值格式。本页帮助读者把载体布局、有限值分解和值分类联系起来；确切契约仍由 ASL 所有者中的 `E5M2NumericFormatDescriptor`、`E5M2FiniteDecomposition` 和 `ClassifyE5M2` 定义。

<!-- PTO-READER-BLOCK: arch-format-e5m2-concepts role=concepts-state -->
## 载体与字段

描述符使用 `8` 位载体、`8` 位逻辑 lane，并且每个载体包含 `1` 个 lane。lane 的符号位位于 `7`，具有 `5` 个指数位、`2` 个尾数位，指数偏置为 `15`。

载体中除符号、指数和尾数字段以外，没有额外的约束位。

<!-- PTO-READER-BLOCK: arch-format-e5m2-rules role=rules-interactions -->
## 分解与分类

`E5M2FiniteDecomposition` 先报告有限值分解是否可用；可用时返回符号、整数有效数和二进制指数。`ClassifyE5M2` 则独立地把原始 lane 归入该格式所支持的零、次正规数、正规数、无穷大或 NaN 类别。

它具有带符号零、次正规数、无穷大、静默 NaN 和信号 NaN。全 1 指数不提供有限值分解；尾数为零时表示无穷大，尾数非零时进入 NaN 类别。

<!-- PTO-READER-BLOCK: arch-format-e5m2-boundaries role=boundaries -->
## 边界与确切编码

`0x00` 和 `0x80` 分别是正零与负零；`0x7e` 是规范静默 NaN。

有限值分解函数在返回的元组中报告可用性；值分类是另一个函数的独立结果。
