## 用途与范围

`E2M1X2` 是已分配的 PTO 数值格式，其数值是以每两个四位 lane 打包进一个八位载体的形式存储；本单元拥有它的描述符、有限值分解、值分类和有符号零编码。

该所有者一次只暴露一个 lane，通过 `value[3:0]` 读取，因此需要读取载体两半的调用方必须自行切出高半部分。

设计要点：该记录把载体宽度与逻辑 lane 宽度分开，因此打包类型在一个载体中报告两个 lane，而单 lane 类型在其载体中只报告自己的 lane 宽度。

<!-- PTO-READER-BLOCK: arch-format-e2m1x2-concepts role=concepts-state -->
## 载体与字段

描述符使用 `8` 位载体、`4` 位逻辑 lane，并且每个载体包含 `2` 个 lane。

lane 的符号位位于 `3`，`2` 个指数位位于 `2:1`，`1` 个尾数位位于 `0:0`，指数偏置为 `1`。

描述符把 `required_low_zero_bits` 和 `required_high_zero_bits` 都设为 `0`，因此每个八位载体容纳两个已定义的 lane 编码。

只需要值类别的读者可以在分类之后停止，因为分类从不要求分解可用。

## 分解与分类

`E2M1X2FiniteDecomposition` 返回可用性、符号、整数有效数和二进制指数，使精确值为 `(-1)^sign * UInt(significand) * 2^exponent`；lane 的指数字段取自 `2:1`，尾数位取自 `0:0`，且 lane `0x2` 与 `0x4` 都分解为有效数 `2`，因为它们的指数字段带有不同的指数标号。

`ClassifyE2M1X2` 把该 lane 归入零、次正规数或带符号的正规数类别；该格式没有无穷大和 NaN 编码，因此每个非零 lane 都表示有限值。

指数字段为零且尾数位为零时选择带符号零；指数字段为零且尾数位为一时选择次正规数形式，有效数为 `1`、指数为 `-1`。

<!-- PTO-READER-BLOCK: arch-format-e2m1x2-boundaries role=boundaries -->
## 边界与确切编码

lane `0x2` 与 `0x4` 都分解为正的有效数 `2`，指数分别为 `-1` 和 `0`；lane `0x3` 与 `0x5` 都分解为有效数 `3`，指数分别为 `-1` 和 `0`；lane `0x2` 到 `0x7` 从指数字段读取指数标号，而 lane `0x1` 使用次正规数形式固定的 `-1`。

设计要点：指数标号并不总是取自指数字段，因此不同指数字段的两个 lane 可以分解出相同的有效数与指数；返回的这一对值仍然精确标识被断言的值。

设计要点：`0x00` 与负编码是同一量值的两个独立编码，因此保留符号位的调用方仍能分辨结果来自哪一个，即使二者都与零相等。

按函数顺序阅读本页：先从描述符取得字段位置，在需要值类别时调用分类函数，并且只在编码有效性通过之后才调用分解函数。
