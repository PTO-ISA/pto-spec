## 用途与范围

E2M1X2 是 PTO 已分配的数值格式。本页帮助读者把载体布局、有限值分解和值分类联系起来；确切契约仍由 ASL 所有者中的 `E2M1X2NumericFormatDescriptor`、`E2M1X2FiniteDecomposition` 和 `ClassifyE2M1X2` 定义。

<!-- PTO-READER-BLOCK: arch-format-e2m1x2-concepts role=concepts-state -->
## 载体与字段

描述符使用 `8` 位载体、`4` 位逻辑 lane，并且每个载体包含 `2` 个 lane。lane 的符号位位于 `3`，具有 `2` 个指数位、`1` 个尾数位，指数偏置为 `1`。

描述符一次描述一个 4 位逻辑 lane；两个 lane 共同占用 8 位载体。

## 分解与分类

`E2M1X2FiniteDecomposition` 先报告有限值分解是否可用；可用时返回符号、整数有效数和二进制指数。`ClassifyE2M1X2` 则独立地把原始 lane 归入该格式所支持的零、次正规数、正规数、无穷大或 NaN 类别。

它具有带符号零，但没有次正规数类别、无穷大或 NaN 类别。每个非零 4 位 lane 都被分类为带符号正规值。

## 边界与确切编码

lane 编码 `0x0` 和 `0x8` 分别表示正零与负零。

有限值分解函数在返回的元组中报告可用性；值分类是另一个函数的独立结果。
