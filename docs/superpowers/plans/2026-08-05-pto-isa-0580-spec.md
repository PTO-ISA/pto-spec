# PTO ISA v0.58 Normative Specification Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Produce a clean PTO ISA 0.58.0 exact head whose catalogs, ASL,
documentation, generated artifacts, and fail-closed CI implement the approved
absolute Shared-register contract.

**Architecture:** Rebase the single reviewed v0.58 delta onto current main,
then replace Shared SSA/version storage with a 256-entry per-core register
bank. Lock each behavior with failing ASL or repository canaries, implement the
smallest semantic change, regenerate projections, and run focused gates before
the full suite.

**Tech Stack:** Git, Bash, Python 3, JSON/TOML, Arm ASL1/ASLRef, Markdown,
GitHub Actions.

## Global Constraints

- Release identity is exactly 0.58.0 and is a hard break from 0.57.1.
- Shared names are S0 through S255; active S#n syntax is rejected.
- Source syntax is C.B.IOS S17; destination syntax is C.B.IOS -> S17.
- C.B.IOS keeps mask 0xc03f, match 0xc03c, and SharedID bits 13:6.
- One private bank exists per four-PE core and all four PEs access it.
- PE_MASK predicates four fixed quarters; 0000 is a no-op.
- Shared TLOAD/TSTORE omit B.IOT for mask 1111 or add one mask-only B.IOT.
- Partial writes preserve unselected quarters and require descriptor
  compatibility when the destination is initialized.
- Concurrent overlap is undefined behavior; no detector or order is added.
- CI and release checks remain fail closed.
- Maturity remains M4 and durable open gaps remain open.
