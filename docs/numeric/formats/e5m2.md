# E5M2

E5M2 is an 8-bit S1/E5/M2 floating format with exponent bias 15.

## Encoding and special values

`S` is bit 7, `E` is bits 6:2, and `M` is bits 1:0. `E=0` encodes zero
or subnormal values. `E=31,M=0` encodes infinity, and `E=31,M!=0`
encodes quiet or signaling NaN. The canonical NaN is `0x7E`.

| Special value | Raw encoding |
| --- | --- |
| Positive infinity | `0x7C` |
| Negative infinity | `0xFC` |
| Canonical quiet NaN | `0x7E` |
| Signaling NaN example | `0x7D` |

## Exact finite value

- Subnormal: `significand=M`, `exponent=-16`.
- Normal: `significand=4+M`, `exponent=E-17`.
- Value: `(-1)^S * significand * 2^exponent`.

Boundaries are `0x01 -> (1,-16)`, `0x03 -> (3,-16)`,
`0x04 -> (4,-16)`, and `0x7B -> (7,13)`.

## Scope

This page defines encoding and exact finite values, not arithmetic or profile
support. Requirements: `PTO-REQ-PROFILE-001`, `PTO-REQ-SCALAR-FP-001`,
`PTO-REQ-HARDWARE-NUMERIC-001`, and `PTO-REQ-CLOSURE-001`.
