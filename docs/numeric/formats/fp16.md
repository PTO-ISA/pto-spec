# FP16

FP16 is a 16-bit fixed binary floating format.

## Encoding

| Field | Bits | Width |
| --- | --- | ---: |
| Sign `S` | 15 | 1 |
| Exponent `E` | 14:10 | 5 |
| Fraction `M` | 9:0 | 10 |

The exponent bias is 15. FP16 defines signed zero, subnormal values, infinity,
quiet NaN, and signaling NaN. Its canonical NaN is `0x7E00`.

| Special value | Raw encoding |
| --- | --- |
| Positive infinity | `0x7C00` |
| Negative infinity | `0xFC00` |
| Canonical quiet NaN | `0x7E00` |
| Signaling NaN example | `0x7C01` |

## Exact finite value

- Zero: `significand = 0`, `exponent = 0`.
- Subnormal: `significand = M`, `exponent = -24`.
- Normal: `significand = 2^10 + M`, `exponent = E - 25`.

## Boundary encodings

| Boundary | Raw | Significand | Exponent |
| --- | --- | ---: | ---: |
| Minimum subnormal | `0x0001` | 1 | -24 |
| Maximum subnormal | `0x03FF` | `0x3FF` | -24 |
| Minimum normal | `0x0400` | `0x400` | -24 |
| Maximum normal | `0x7BFF` | `0x7FF` | 5 |

## Scope

This page defines encoding and exact finite values only. Requirements:
`PTO-REQ-PROFILE-001`, `PTO-REQ-SCALAR-FP-001`,
`PTO-REQ-HARDWARE-NUMERIC-001`, and `PTO-REQ-CLOSURE-001`.
