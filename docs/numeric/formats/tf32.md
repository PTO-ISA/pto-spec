# TF32

TF32 is an E8M10 value in a 32-bit carrier. Bits 12:0 must be zero; a nonzero
discarded bit makes the encoding invalid.

## Encoding

| Field | Bits | Width |
| --- | --- | ---: |
| Sign `S` | 31 | 1 |
| Exponent `E` | 30:23 | 8 |
| Fraction `M` | 22:13 | 10 |
| Required zero | 12:0 | 13 |

The exponent bias is 127. TF32 defines signed zero, subnormal values, infinity,
quiet NaN, and signaling NaN. Its canonical NaN is `0x7FC00000`.

| Special value | Raw encoding |
| --- | --- |
| Positive infinity | `0x7F800000` |
| Negative infinity | `0xFF800000` |
| Canonical quiet NaN | `0x7FC00000` |
| Signaling NaN example | `0x7F802000` |

## Exact finite value

- Zero: `significand = 0`, `exponent = 0`.
- Subnormal: `significand = M`, `exponent = -136`.
- Normal: `significand = 2^10 + M`, `exponent = E - 137`.

The value is `(-1)^S * significand * 2^exponent`.

## Boundary encodings

| Boundary | Raw | Significand | Exponent |
| --- | --- | ---: | ---: |
| Minimum subnormal | `0x00002000` | 1 | -136 |
| Maximum subnormal | `0x007FE000` | `0x3FF` | -136 |
| Minimum normal | `0x00800000` | `0x400` | -136 |
| Maximum normal | `0x7F7FE000` | `0x7FF` | 117 |

## Scope

This page defines encoding and exact finite values only. Requirements:
`PTO-REQ-PROFILE-001`, `PTO-REQ-SCALAR-FP-001`,
`PTO-REQ-HARDWARE-NUMERIC-001`, and `PTO-REQ-CLOSURE-001`.
