# E3M2

E3M2 is a 6-bit S1/E3/M2 finite format carried in a zero-extended byte.
Bits 7:6 must be zero. The exponent bias is 3.

## Encoding

`S` is bit 5, `E` is bits 4:2, and `M` is bits 1:0. `E=0,M=0`
encodes signed zero, `E=0,M!=0` encodes subnormal values, and every nonzero
exponent encodes a normal value. E3M2 has no infinity or NaN.

## Exact finite value

- Subnormal: `significand=M`, `exponent=-4`.
- Normal: `significand=4+M`, `exponent=E-5`.
- Value: `(-1)^S * significand * 2^exponent`.

Boundaries are `0x01 -> (1,-4)`, `0x03 -> (3,-4)`,
`0x04 -> (4,-4)`, and `0x1F -> (7,2)`, whose maximum is 28.

The base value is unscaled. E8M0 application is operation/profile behavior.

## Scope

Requirements: `PTO-REQ-PROFILE-001`, `PTO-REQ-SCALAR-FP-001`,
`PTO-REQ-HARDWARE-NUMERIC-001`, and `PTO-REQ-CLOSURE-001`.
