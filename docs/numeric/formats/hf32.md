# HF32

HF32 is an E8M11 value in a 32-bit carrier. Bits 11:0 must be zero; a nonzero
discarded bit makes the encoding invalid.

## Encoding

| Field | Bits | Width |
| --- | --- | ---: |
| Sign `S` | 31 | 1 |
| Exponent `E` | 30:23 | 8 |
| Fraction `M` | 22:12 | 11 |
| Required zero | 11:0 | 12 |

The exponent bias is 127. HF32 defines signed zero, subnormal values, infinity,
quiet NaN, and signaling NaN. Its canonical NaN is `0x7FC00000`.

| Special value | Raw encoding |
| --- | --- |
| Positive infinity | `0x7F800000` |
| Negative infinity | `0xFF800000` |
| Canonical quiet NaN | `0x7FC00000` |
| Signaling NaN example | `0x7F801000` |

## Exact finite value

- Zero: `significand = 0`, `exponent = 0`.
- Subnormal: `significand = M`, `exponent = -137`.
- Normal: `significand = 2^11 + M`, `exponent = E - 138`.

The value is `(-1)^S * significand * 2^exponent`.

## Boundary encodings

| Boundary | Raw | Significand | Exponent |
| --- | --- | ---: | ---: |
| Minimum subnormal | `0x00001000` | 1 | -137 |
| Maximum subnormal | `0x007FF000` | `0x7FF` | -137 |
| Minimum normal | `0x00800000` | `0x800` | -137 |
| Maximum normal | `0x7F7FF000` | `0xFFF` | 116 |

## Scope

This page defines encoding and exact finite values only. Requirements:
`PTO-REQ-PROFILE-001`, `PTO-REQ-SCALAR-FP-001`,
`PTO-REQ-HARDWARE-NUMERIC-001`, and `PTO-REQ-CLOSURE-001`.
