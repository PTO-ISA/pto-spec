# E8M0

E8M0 is an unsigned eight-bit power-of-two scale format. It has no zero,
signed zero, subnormal, or infinity encoding.

## Encoding

Raw values `0x00..0xFE` represent:

```text
significand = 1
exponent = raw - 127
value = 2^exponent
```

The finite range is therefore `2^-127` through `2^127`. Raw `0xFF` is quiet
NaN and is the canonical NaN.

## Microscaling block

One E8M0 scale is shared by 32 logical K elements. The base low-precision
format decoder and E8M0 decoder remain independent. Scale lookup,
multiplication, accumulation, rounding, and NaN propagation are operation and
profile contracts.

## Scope

Requirements: `PTO-REQ-PROFILE-001`, `PTO-REQ-SCALAR-FP-001`,
`PTO-REQ-HARDWARE-NUMERIC-001`, and `PTO-REQ-CLOSURE-001`.
