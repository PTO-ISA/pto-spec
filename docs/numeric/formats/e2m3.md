# E2M3

E2M3 is a 6-bit S1/E2/M3 finite format carried in a zero-extended byte.
Bits 7:6 must be zero. The exponent bias is 1.

## Encoding

`S` is bit 5, `E` is bits 4:3, and `M` is bits 2:0. `E=0,M=0`
encodes signed zero, `E=0,M!=0` encodes subnormal values, and every nonzero
exponent encodes a normal value. E2M3 has no infinity or NaN.

## Exact finite value

- Subnormal: `significand=M`, `exponent=-3`.
- Normal: `significand=8+M`, `exponent=E-4`.
- Value: `(-1)^S * significand * 2^exponent`.

Boundaries are `0x01 -> (1,-3)`, `0x07 -> (7,-3)`,
`0x08 -> (8,-3)`, and `0x1F -> (15,-1)`, whose maximum is 7.5.

The base value is unscaled. E8M0 application is operation/profile behavior.

## Scope

Requirements: `PTO-REQ-PROFILE-001`, `PTO-REQ-SCALAR-FP-001`,
`PTO-REQ-HARDWARE-NUMERIC-001`, and `PTO-REQ-CLOSURE-001`.
