# E1M2X2

E1M2X2 stores two logical E1M2 lanes in one byte. Each lane is a finite
four-bit S1/E1/M2 value with exponent bias 1.

## Lane encoding

Within one lane, `S` is bit 3, `E` is bit 2, and `M` is bits 1:0. The
low-index lane occupies the low nibble and the high-index lane occupies the
high nibble, with sibling preservation on stores.

| Raw lane | Value |
| ---: | ---: |
| `0x0` | 0 |
| `0x1` | 0.25 |
| `0x2` | 0.5 |
| `0x3` | 0.75 |
| `0x4` | 1 |
| `0x5` | 1.25 |
| `0x6` | 1.5 |
| `0x7` | 1.75 |
| `0x8` | -0 |
| `0x9` | -0.25 |
| `0xA` | -0.5 |
| `0xB` | -0.75 |
| `0xC` | -1 |
| `0xD` | -1.25 |
| `0xE` | -1.5 |
| `0xF` | -1.75 |

Every nonzero finite value uses `exponent=-2`; its significand is the low two
bits for `E=0` and `4+M` for `E=1`. The format has no infinity, quiet NaN, or
signaling NaN.

The normative packing and sibling-preservation rules are in
[ADR 0033](../../architecture-decisions/0033-tlsu-four-bit-memory-packing.md).

## Scope

Scale application is operation/profile behavior. Requirements:
`PTO-REQ-PROFILE-001`, `PTO-REQ-SCALAR-FP-001`,
`PTO-REQ-HARDWARE-NUMERIC-001`, and `PTO-REQ-CLOSURE-001`.
