# FP64

FP64 is a 64-bit fixed binary floating format with one logical value per
64-bit carrier.

## Encoding

| Field | Bits | Width |
| --- | --- | ---: |
| Sign `S` | 63 | 1 |
| Exponent `E` | 62:52 | 11 |
| Fraction `M` | 51:0 | 52 |

The exponent bias is 1023. FP64 defines signed zero, subnormal values,
infinity, quiet NaN, and signaling NaN. Its canonical NaN is
`0x7FF8000000000000`.

| Special value | Raw encoding |
| --- | --- |
| Positive infinity | `0x7FF0000000000000` |
| Negative infinity | `0xFFF0000000000000` |
| Canonical quiet NaN | `0x7FF8000000000000` |
| Signaling NaN example | `0x7FF0000000000001` |

## Exact finite value

- Zero: `significand = 0`, `exponent = 0`.
- Subnormal: `significand = M`, `exponent = -1074`.
- Normal: `significand = 2^52 + M`, `exponent = E - 1075`.

The value is `(-1)^S * significand * 2^exponent`. Infinity and NaN have no
finite decomposition.

## Boundary encodings

| Boundary | Raw encoding | Significand | Exponent |
| --- | --- | ---: | ---: |
| Minimum positive subnormal | `0x0000000000000001` | 1 | -1074 |
| Maximum positive subnormal | `0x000FFFFFFFFFFFFF` | `0xFFFFFFFFFFFFF` | -1074 |
| Minimum positive normal | `0x0010000000000000` | `0x10000000000000` | -1074 |
| Maximum positive normal | `0x7FEFFFFFFFFFFFFF` | `0x1FFFFFFFFFFFFF` | 971 |

## Scope

This page defines encoding and exact finite values only. Arithmetic, rounding,
flags, and operation/type support remain profile contracts. Requirements:
`PTO-REQ-PROFILE-001`, `PTO-REQ-SCALAR-FP-001`,
`PTO-REQ-HARDWARE-NUMERIC-001`, and `PTO-REQ-CLOSURE-001`.
