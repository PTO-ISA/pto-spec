# E2M1X2

E2M1X2 stores two logical E2M1 lanes in one byte. Each lane is a finite
four-bit S1/E2/M1 value with exponent bias 1.

## Lane encoding

Within one logical lane, `S` is bit 3, `E` is bits 2:1, and `M` is bit 0.
The even or low-index lane occupies byte bits 3:0; the odd or high-index lane
occupies bits 7:4. A selected-lane store preserves its sibling lane.

| Raw lane | Value |
| ---: | ---: |
| `0x0` | 0 |
| `0x1` | 0.5 |
| `0x2` | 1 |
| `0x3` | 1.5 |
| `0x4` | 2 |
| `0x5` | 3 |
| `0x6` | 4 |
| `0x7` | 6 |
| `0x8` | -0 |
| `0x9` | -0.5 |
| `0xA` | -1 |
| `0xB` | -1.5 |
| `0xC` | -2 |
| `0xD` | -3 |
| `0xE` | -4 |
| `0xF` | -6 |

The format has no infinity, quiet NaN, or signaling NaN.

## Exact finite value

`E=0,M=1` decomposes to `significand=1, exponent=-1`. For `E!=0`,
`significand=2+M` and `exponent=E-2`. The decoder consumes one logical
low-nibble lane; byte packing is handled separately.

The normative packing and sibling-preservation rules are in
[ADR 0033](../../architecture-decisions/0033-tlsu-four-bit-memory-packing.md).

## Scope

Scale application is operation/profile behavior. Requirements:
`PTO-REQ-PROFILE-001`, `PTO-REQ-SCALAR-FP-001`,
`PTO-REQ-HARDWARE-NUMERIC-001`, and `PTO-REQ-CLOSURE-001`.
