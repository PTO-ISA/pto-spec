# FP32

FP32 is a 32-bit fixed binary floating format with one logical value per
32-bit carrier.

## Encoding

| Field | Bits | Width |
| --- | --- | ---: |
| Sign `S` | 31 | 1 |
| Exponent `E` | 30:23 | 8 |
| Fraction `M` | 22:0 | 23 |

The exponent bias is 127. FP32 defines signed zero, subnormal values, infinity,
quiet NaN, and signaling NaN. Its canonical NaN is `0x7FC00000`.

| Special value | Raw encoding |
| --- | --- |
| Positive infinity | `0x7F800000` |
| Negative infinity | `0xFF800000` |
| Canonical quiet NaN | `0x7FC00000` |
| Signaling NaN example | `0x7F800001` |

## Exact finite value

- Zero: `significand = 0`, `exponent = 0`.
- Subnormal: `significand = M`, `exponent = -149`.
- Normal: `significand = 2^23 + M`, `exponent = E - 150`.

The value is `(-1)^S * significand * 2^exponent`.

## Boundary encodings

| Boundary | Raw | Significand | Exponent |
| --- | --- | ---: | ---: |
| Minimum subnormal | `0x00000001` | 1 | -149 |
| Maximum subnormal | `0x007FFFFF` | `0x7FFFFF` | -149 |
| Minimum normal | `0x00800000` | `0x800000` | -149 |
| Maximum normal | `0x7F7FFFFF` | `0xFFFFFF` | 104 |

## Scope

This page defines encoding and exact finite values only. Requirements:
`PTO-REQ-PROFILE-001`, `PTO-REQ-SCALAR-FP-001`,
`PTO-REQ-HARDWARE-NUMERIC-001`, and `PTO-REQ-CLOSURE-001`.
