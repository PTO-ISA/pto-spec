# E4M3

E4M3 is an 8-bit S1/E4/M3 floating format with exponent bias 7.

## Encoding and special values

`S` is bit 7, `E` is bits 6:3, and `M` is bits 2:0. `E=0,M=0`
encodes signed zero; `E=0,M!=0` encodes subnormal values. E4M3 has no
infinity. `E=15,M=7` is quiet NaN for either sign; all other `E=15`
encodings are finite normals. The canonical NaN is `0x7F`.

## Exact finite value

- Subnormal: `significand=M`, `exponent=-9`.
- Normal: `significand=8+M`, `exponent=E-10`.
- Value: `(-1)^S * significand * 2^exponent`.

Boundaries are `0x01 -> (1,-9)`, `0x07 -> (7,-9)`,
`0x08 -> (8,-9)`, and `0x7E -> (14,5)`.

## Scope

This page defines encoding and exact finite values, not arithmetic or profile
support. Requirements: `PTO-REQ-PROFILE-001`, `PTO-REQ-SCALAR-FP-001`,
`PTO-REQ-HARDWARE-NUMERIC-001`, and `PTO-REQ-CLOSURE-001`.
