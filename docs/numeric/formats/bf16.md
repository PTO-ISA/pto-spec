# BF16

BF16 is a 16-bit E8M7 floating format.

## Encoding

| Field | Bits | Width |
| --- | --- | ---: |
| Sign `S` | 15 | 1 |
| Exponent `E` | 14:7 | 8 |
| Fraction `M` | 6:0 | 7 |

The exponent bias is 127. BF16 defines signed zero, subnormal values, infinity,
quiet NaN, and signaling NaN. Its canonical NaN is `0x7FC0`.

| Special value | Raw encoding |
| --- | --- |
| Positive infinity | `0x7F80` |
| Negative infinity | `0xFF80` |
| Canonical quiet NaN | `0x7FC0` |
| Signaling NaN example | `0x7F81` |

## Exact finite value

- Zero: `significand = 0`, `exponent = 0`.
- Subnormal: `significand = M`, `exponent = -133`.
- Normal: `significand = 2^7 + M`, `exponent = E - 134`.

## Boundary encodings

| Boundary | Raw | Significand | Exponent |
| --- | --- | ---: | ---: |
| Minimum subnormal | `0x0001` | 1 | -133 |
| Maximum subnormal | `0x007F` | `0x7F` | -133 |
| Minimum normal | `0x0080` | `0x80` | -133 |
| Maximum normal | `0x7F7F` | `0xFF` | 120 |

## Scope

This page defines encoding and exact finite values only. Requirements:
`PTO-REQ-PROFILE-001`, `PTO-REQ-SCALAR-FP-001`,
`PTO-REQ-HARDWARE-NUMERIC-001`, and `PTO-REQ-CLOSURE-001`.
