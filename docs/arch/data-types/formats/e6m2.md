## Purpose and scope

E6M2 is an unsigned eight-bit PTO scale format. This page helps a reader connect its raw fields, exact finite value, and value classification; the ASL owner remains the exact definition and also supplies the E6M2 decoder used by a HiF4 scale word.

<!-- PTO-READER-BLOCK: arch-format-e6m2-concepts role=concepts-state -->
## Carrier and fields

The descriptor uses an `8`-bit carrier, an `8`-bit logical lane, and `1` lane per carrier. Bits `7:2` form a six-bit exponent with bias `48`, bits `1:0` form a two-bit fraction, and the finite significand has a hidden leading one; there is no sign bit.

No carrier bits are constrained outside those exponent and fraction fields.

<!-- PTO-READER-BLOCK: arch-format-e6m2-rules role=rules-interactions -->
## Exact value and classification

For codes `0x00` through `0xfe`, `E6M2FiniteValue` returns `(4 + fraction) / 4 * 2^(exponent - 48)`. The matching finite decomposition is positive, uses integer significand `4 + fraction`, and uses binary exponent `exponent - 50`.

Every code in that finite range is a positive normal value. Code `0xff` is a quiet NaN and has no finite decomposition; the format has no zero, signed zero, subnormal, infinity, or signaling NaN encoding.

<!-- PTO-READER-BLOCK: arch-format-e6m2-boundaries role=boundaries -->
## Boundaries and exact encodings

`0x00` is the smallest finite code and denotes `2^-48`; `0xfe` is the largest finite code and denotes `1.5 * 2^15`. `0xff` is both the sole quiet-NaN code and the canonical NaN returned by the owner.

The all-one code is excluded before finite-value evaluation, while classification independently identifies it as quiet NaN.
