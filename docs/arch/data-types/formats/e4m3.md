## Purpose and scope

`E4M3` is an assigned PTO numeric format stored in an eight-bit carrier, and this unit is the exact owner of its descriptor, finite decomposition, value classification, canonical NaN, and signed zero encodings.

It packs four exponent bits and three fraction bits into one byte, so every finite value is an integer significand times a power of two and the range is wide for its carrier size.

Design point: the record keeps the carrier width and the logical lane width separate, so a packed type reports two lanes in one carrier while a single-lane type reports only its own lane width in its carrier.

<!-- PTO-READER-BLOCK: arch-format-e4m3-concepts role=concepts-state -->
## Carrier and fields

The descriptor uses a `8`-bit carrier, a `8`-bit logical lane, and `1` lane per carrier.

The lane has one sign bit at position `7`, `4` exponent bit(s) in `6:3`, `3` fraction bit(s) in `2:0`, and exponent bias `7`.

The descriptor sets `required_low_zero_bits` and `required_high_zero_bits` to `0`, so every eight-bit lane is a defined encoding.

## Decomposition and classification

`E4M3FiniteDecomposition` returns availability, the sign, an integer significand, and a binary exponent such that the exact value is `(-1)^sign * UInt(significand) * 2^exponent`.

`ClassifyE4M3` assigns the raw lane to zero, subnormal, normal, or NaN classes; the format has no infinity and no signaling NaN, so the only non-finite encoding is an all-one exponent together with an all-one fraction.

An exponent field of zero with a nonzero fraction selects the subnormal form, and an all-one exponent with an all-one fraction makes the decomposition unavailable and classifies as quiet NaN.

Design point: writing `FALSE` for availability instead of an arbitrary significand keeps a consumer from reading the placeholder fields of a non-finite carrier as a number, so the availability flag must be consulted first.

<!-- PTO-READER-BLOCK: arch-format-e4m3-boundaries role=boundaries -->
## Boundaries and exact encodings

The all-one exponent clause tests the fraction as well, so an encoding whose exponent field is all ones and whose fraction bits are not all ones is an ordinary finite normal in this format, and the only non-finite encodings are those that combine an all-one exponent with an all-one fraction.

Design point: reserving one all-ones encoding for quiet NaN while keeping the other seven all-ones encodings finite is what makes the largest finite value `0x7e` and widens the finite range beyond what an infinity encoding would allow.

Design point: `0x00` and the negative encoding are separate encodings of the same magnitude, so a consumer that preserves the sign bit can still tell which one produced a result even when both compare equal to zero.

Read this page in the order of the functions: take the field positions from the descriptor, call the classification function when the value class matters, and call the decomposition function when the exact significand and exponent are needed.

## Non-normative reading example

This example illustrates the current ASL owner and does not replace the normative operation.

`0x01` is the smallest positive subnormal and denotes `1 * 2^-9`; `0x08` is the first positive normal and denotes `8 * 2^-9`, which is `1 * 2^-6`.

`0x7e` is the largest finite value and decomposes to significand `14` with exponent `5`, which is `1.75 * 2^8`.
