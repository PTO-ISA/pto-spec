## Purpose and scope

This unit defines the exact `TF32` carrier contract used by the numeric-format dispatch: descriptor, encoding validity, finite decomposition, classification, canonical NaN, and signed zeros.

It keeps the architectural ten-bit fraction distinct from an arbitrary 32-bit host floating-point value.

<!-- PTO-READER-BLOCK: arch-tf32-concepts-state role=concepts-state -->
## Concepts and visible state

- `TF32NumericFormatDescriptor` uses a 32-bit carrier with one sign bit, eight exponent bits, ten fraction bits, bias `127`, and `13` required low zero bits.
- `TF32EncodingValid` checks those `13` low bits. `TF32FiniteDecomposition` then exposes an exact sign, integer significand, and base-two exponent for valid finite values.
- `ClassifyTF32` distinguishes signed zero, signed subnormal, signed normal, signed infinity, quiet NaN, and signaling NaN from the architectural exponent and fraction fields.

<!-- PTO-READER-BLOCK: arch-tf32-rules-interactions role=rules-interactions -->
## Rules and interactions

A carrier with any nonzero bit in `[12:0]` is invalid for `TF32`, even if its upper 19 bits resemble a valid value.

Exponent `0xff` selects infinity when the ten-bit fraction is zero; otherwise fraction bit `9` distinguishes quiet from signaling NaN.

`TF32CanonicalNaN` is `0x7fc00000`; `TF32SignedZeroEncodings` returns `0x00000000` and `0x80000000`.

<!-- PTO-READER-BLOCK: arch-tf32-boundaries role=boundaries -->
## Architectural boundaries

Finite decomposition reports unavailable for invalid encodings, infinities, and NaNs. The returned placeholder fields are not a numeric result when availability is false.

Bits above the architectural 32-bit carrier are outside this unit; callers pass `value[31:0]` through the numeric-format dispatcher.

<!-- PTO-READER-BLOCK: arch-tf32-example-usage role=example-usage -->
## Non-normative reading example

`0x3f800000` is a valid normal carrier and decomposes exactly. `0x3f800001` fails `TF32EncodingValid` because a required low-zero bit is set.

When reading a consumer, check encoding validity before treating classification or decomposition fields as a usable finite value.
