## Purpose and scope

FP16 is an assigned PTO numeric format. This page helps a reader connect its carrier layout, finite-value decomposition, and value classification; the exact contract remains in `FP16NumericFormatDescriptor`, `FP16FiniteDecomposition`, and `ClassifyFP16` in the ASL owner.

<!-- PTO-READER-BLOCK: arch-format-fp16-concepts role=concepts-state -->
## Carrier and fields

The descriptor uses a `16`-bit carrier, a `16`-bit logical lane, and `1` lane(s) per carrier. The lane has one sign bit at position `15`, `5` exponent bit(s), `10` fraction bit(s), and exponent bias `15`.

No carrier bits are constrained outside the sign, exponent, and fraction fields.

<!-- PTO-READER-BLOCK: arch-format-fp16-rules role=rules-interactions -->
## Decomposition and classification

`FP16FiniteDecomposition` reports whether a finite decomposition is available and, when available, returns the sign, an integer significand, and a binary exponent. `ClassifyFP16` separately assigns the raw lane to zero, subnormal, normal, infinity, or NaN classes supported by this format.

It has signed zero, subnormals, infinities, quiet NaNs, and signaling NaNs. An all-one exponent is not a finite decomposition; a zero fraction selects infinity and a nonzero fraction selects a NaN class.

<!-- PTO-READER-BLOCK: arch-format-fp16-boundaries role=boundaries -->
## Boundaries and exact encodings

`0x0000` and `0x8000` are positive and negative zero; `0x7e00` is the canonical quiet NaN.

The finite-decomposition function reports availability with its returned tuple; value classification is a separate function result.

This example illustrates how to read the functions; it does not add an encoding rule.

begin

pure func ClassifyFP16(value: bits(16)) => NumericValueClass
begin
    let exponent = value[14:10];
    let fraction = value[9:0];
    if exponent == Ones{5} then
        if fraction == Zeros{10} then
            if value[15] == '1' then return NumericValue_NegativeInfinity;
            else return NumericValue_PositiveInfinity;
            end;
        elsif fraction[9] == '1' then return NumericValue_QuietNaN;
        else return NumericValue_SignalingNaN;
        end;
    end;
    return NumericValueClassFromFiniteSign(value[15],
        exponent == Zeros{5} && fraction == Zeros{10},
        exponent == Zeros{5} && fraction != Zeros{10});
end;
