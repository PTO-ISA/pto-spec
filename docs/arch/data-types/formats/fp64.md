## Purpose and scope

FP64 is an assigned PTO numeric format. This page helps a reader connect its carrier layout, finite-value decomposition, and value classification; the exact contract remains in `FP64NumericFormatDescriptor`, `FP64FiniteDecomposition`, and `ClassifyFP64` in the ASL owner.

<!-- PTO-READER-BLOCK: arch-format-fp64-concepts role=concepts-state -->
## Carrier and fields

The descriptor uses a `64`-bit carrier, a `64`-bit logical lane, and `1` lane(s) per carrier. The lane has one sign bit at position `63`, `11` exponent bit(s), `52` fraction bit(s), and exponent bias `1023`.

No carrier bits are constrained outside the sign, exponent, and fraction fields.

<!-- PTO-READER-BLOCK: arch-format-fp64-rules role=rules-interactions -->
## Decomposition and classification

`FP64FiniteDecomposition` reports whether a finite decomposition is available and, when available, returns the sign, an integer significand, and a binary exponent. `ClassifyFP64` separately assigns the raw lane to zero, subnormal, normal, infinity, or NaN classes supported by this format.

It has signed zero, subnormals, infinities, quiet NaNs, and signaling NaNs. An all-one exponent is not a finite decomposition; a zero fraction selects infinity and a nonzero fraction selects a NaN class.

<!-- PTO-READER-BLOCK: arch-format-fp64-boundaries role=boundaries -->
## Boundaries and exact encodings

`0x0000000000000000` and `0x8000000000000000` are positive and negative zero; `0x7ff8000000000000` is the canonical quiet NaN.

The finite-decomposition function reports availability with its returned tuple; value classification is a separate function result.

## Non-normative reading example

This example illustrates how to read the functions; it does not add an encoding rule.

For example, `0x3ff0000000000000` decomposes to positive significand `0x0010000000000000` with exponent `-52`, while `0x7ff0000000000000` is positive infinity and has no finite decomposition.

pure func ClassifyFP64(value: Word) => NumericValueClass
begin
    let exponent = value[62:52];
    let fraction = value[51:0];
    if exponent == Ones{11} then
        if fraction == Zeros{52} then
            if value[63] == '1' then return NumericValue_NegativeInfinity;
            else return NumericValue_PositiveInfinity;

        else return NumericValue_SignalingNaN;

        exponent == Zeros{11} && fraction == Zeros{52},
        exponent == Zeros{11} && fraction != Zeros{52});
