## Purpose and scope

BF16 is an assigned PTO numeric format. This page helps a reader connect its carrier layout, finite-value decomposition, and value classification; the exact contract remains in `BF16NumericFormatDescriptor`, `BF16FiniteDecomposition`, and `ClassifyBF16` in the ASL owner.

<!-- PTO-READER-BLOCK: arch-format-bf16-concepts role=concepts-state -->
## Carrier and fields

The descriptor uses a `16`-bit carrier, a `16`-bit logical lane, and `1` lane(s) per carrier. The lane has one sign bit at position `15`, `8` exponent bit(s), `7` fraction bit(s), and exponent bias `127`.

No carrier bits are constrained outside the sign, exponent, and fraction fields.

<!-- PTO-READER-BLOCK: arch-format-bf16-rules role=rules-interactions -->
## Decomposition and classification

`BF16FiniteDecomposition` reports whether a finite decomposition is available and, when available, returns the sign, an integer significand, and a binary exponent. `ClassifyBF16` separately assigns the raw lane to zero, subnormal, normal, infinity, or NaN classes supported by this format.

It has signed zero, subnormals, infinities, quiet NaNs, and signaling NaNs. An all-one exponent is not a finite decomposition; a zero fraction selects infinity and a nonzero fraction selects a NaN class.

<!-- PTO-READER-BLOCK: arch-format-bf16-boundaries role=boundaries -->
## Boundaries and exact encodings

`0x0000` and `0x8000` are the positive and negative zero encodings; `0x7fc0` is the canonical quiet NaN.

The finite-decomposition function reports availability with its returned tuple; value classification is a separate function result.

pure func ClassifyBF16(value: bits(16)) => NumericValueClass
begin
    let exponent = value[14:7];
    let fraction = value[6:0];
    if exponent == Ones{8} then
