## Carrier and fields

The descriptor uses an `8`-bit carrier with one `8`-bit logical lane. All `8` lane bits form the exponent field, the exponent bias is `127`, and the format has no sign or fraction field.

All eight bits form an unsigned exponent field; there is no sign or fraction field.

<!-- PTO-READER-BLOCK: arch-format-e8m0-rules role=rules-interactions -->
## Decomposition and classification

`E8M0FiniteDecomposition` reports whether a finite decomposition is available and, when available, returns the sign, an integer significand, and a binary exponent. `ClassifyE8M0` separately assigns the raw lane to zero, subnormal, normal, infinity, or NaN classes supported by this format.

It has no zero, signed zero, subnormal, or infinity class. Encodings `0x00` through `0xfe` are positive normal powers of two, while `0xff` is the quiet-NaN encoding and has no finite decomposition.

## Boundaries and exact encodings

`E8M0CanonicalNaN` returns `0xff`, and `HardwareNumericScaleBlockElements` fixes a scale block at `32` elements.

The finite-decomposition function reports availability with its returned tuple; value classification is a separate function result.
