## Purpose and scope

`E2M1X2` is an assigned PTO numeric format whose values are four-bit lanes packed two per eight-bit carrier, and this unit owns its descriptor, finite decomposition, value classification, and signed zero encodings.

The owner exposes one lane at a time through `value[3:0]`, so a consumer that reads both halves of a carrier must slice the upper lane itself.

Design point: the record keeps the carrier width and the logical lane width separate, so a packed type reports two lanes in one carrier while a single-lane type reports only its own lane width in its carrier.

<!-- PTO-READER-BLOCK: arch-format-e2m1x2-concepts role=concepts-state -->
## Carrier and fields

The descriptor uses a `8`-bit carrier, a `4`-bit logical lane, and `2` lanes per carrier.

The lane has one sign bit at position `3`, `2` exponent bit(s) in `2:1`, `1` fraction bit(s) in `0:0`, and exponent bias `1`.

The descriptor sets `required_low_zero_bits` and `required_high_zero_bits` to `0`, so every eight-bit carrier holds two defined lane encodings.

A reader that only needs a value class can stop after classification, because classification never requires an available decomposition.

## Decomposition and classification

`E2M1X2FiniteDecomposition` returns availability, the sign, an integer significand, and a binary exponent such that the exact value is `(-1)^sign * UInt(significand) * 2^exponent`; the lane exponent field is read at `2:1` and the fraction bit at `0:0`, and lanes `0x2` and `0x4` both decompose to significand `2` because their exponent fields carry different exponent labels.

`ClassifyE2M1X2` assigns the lane to a zero, a subnormal, or a signed normal class; the format has no infinity and no NaN encoding, so every non-zero lane denotes a finite value.

An exponent field of zero with the zero fraction bit selects a signed zero, while an exponent field of zero with the fraction bit set selects the subnormal form with significand `1` and exponent `-1`.

<!-- PTO-READER-BLOCK: arch-format-e2m1x2-boundaries role=boundaries -->
## Boundaries and exact encodings

Lanes `0x2` and `0x4` both decompose to a positive significand of `2`, with exponents `-1` and `0`; lanes `0x3` and `0x5` both decompose to significand `3`, with exponents `-1` and `0`; lanes `0x2` through `0x7` read their exponent label from the exponent field while lane `0x1` uses the fixed `-1` of the subnormal form.

Design point: the exponent label is not always read from the exponent field, so two lanes with different exponent fields can decompose to the same significand and exponent; the returned pair still identifies the asserted value exactly.

Design point: `0x00` and the negative encoding are separate encodings of the same magnitude, so a consumer that preserves the sign bit can still tell which one produced a result even when both compare equal to zero.

Read this page in the order of the functions: take the field positions from the descriptor, call the classification function when the value class matters, and call the decomposition function only after encoding validity has passed.
