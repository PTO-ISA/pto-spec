## Purpose and scope

FP32 is an assigned PTO numeric format. This page helps a reader connect its carrier layout, finite-value decomposition, and value classification; the exact contract remains in `FP32NumericFormatDescriptor`, `FP32FiniteDecomposition`, and `ClassifyFP32` in the ASL owner.

<!-- PTO-READER-BLOCK: arch-format-fp32-concepts role=concepts-state -->
## Carrier and fields

The descriptor uses a `32`-bit carrier, a `32`-bit logical lane, and `1` lane(s) per carrier. The lane has one sign bit at position `31`, `8` exponent bit(s), `23` fraction bit(s), and exponent bias `127`.

No carrier bits are constrained outside the sign, exponent, and fraction fields.

<!-- PTO-READER-BLOCK: arch-format-fp32-rules role=rules-interactions -->
## Decomposition and classification

`FP32FiniteDecomposition` reports whether a finite decomposition is available and, when available, returns the sign, an integer significand, and a binary exponent. `ClassifyFP32` separately assigns the raw lane to zero, subnormal, normal, infinity, or NaN classes supported by this format.

It has signed zero, subnormals, infinities, quiet NaNs, and signaling NaNs. An all-one exponent is not a finite decomposition; a zero fraction selects infinity and a nonzero fraction selects a NaN class.

<!-- PTO-READER-BLOCK: arch-format-fp32-boundaries role=boundaries -->
## Boundaries and exact encodings

`0x00000000` and `0x80000000` are positive and negative zero; `0x7fc00000` is the canonical quiet NaN.

The finite-decomposition function reports availability with its returned tuple; value classification is a separate function result.

<!-- PTO-READER-BLOCK: arch-format-fp32-example role=example-usage -->
## Non-normative reading example

This example illustrates how to read the functions; it does not add an encoding rule.

For example, `0x3f800000` decomposes to positive significand `0x00800000` with exponent `-23`, while `0x7f800000` is positive infinity and has no finite decomposition.

pure func FP32FiniteDecomposition(value: bits(32))
    => (boolean, boolean, Word, integer {-1074..1023})
begin
    let exponent = value[30:23];
    let fraction = value[22:0];
    if exponent == Ones{8} then
        return (FALSE, FALSE, Zeros{PTO_XLEN}, 0);

        if fraction == Zeros{23} then

        end;
    else return (TRUE, value[31] == '1',
                 LSL(Zeros{PTO_XLEN} + 1, 23) +
                     ZeroExtend{PTO_XLEN}(fraction),

    end;
end;
pure func ClassifyFP32(value: bits(32)) => NumericValueClass
begin
    let exponent = value[30:23];
    let fraction = value[22:0];
    if exponent == Ones{8} then
        if fraction == Zeros{23} then
            if value[31] == '1' then return NumericValue_NegativeInfinity;
            else return NumericValue_PositiveInfinity;
            end;
        elsif fraction[22] == '1' then return NumericValue_QuietNaN;
        else return NumericValue_SignalingNaN;
        end;
    end;
    return NumericValueClassFromFiniteSign(value[31],
        exponent == Zeros{8} && fraction == Zeros{23},
        exponent == Zeros{8} && fraction != Zeros{23});
end;
