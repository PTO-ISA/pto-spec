## Purpose and scope

`FP19` is the nineteen-bit scalar and vector parameter carrier consumed by `B.FPATR`, and this unit owns its representation, its legal parameter domains, its finite interpretation, and its conversion from `FP32`.

The unit also names the two parameter roles: a B.FPATR scale must be a positive normal value, and an activation parameter must be positive zero or a positive normal value.

<!-- PTO-READER-BLOCK: arch-fp19-concepts-state role=concepts-state -->
## Concepts and visible state

The layout is one sign bit at `18`, an eight-bit exponent in `17:10` with bias `127`, and a ten-bit fraction in `9:0`.

`FP19ValueClass` uses the exponent and fraction fields to return `NumericValue_PositiveZero`, `NumericValue_NegativeZero`, a signed subnormal, a signed normal, a signed infinity, `NumericValue_QuietNaN`, or `NumericValue_SignalingNaN`.

`FP19FiniteValue` interprets a finite carrier, and `FP32ToFP19` narrows an `FP32` carrier by keeping the upper ten fraction bits and rounding the discarded bits to nearest with ties to even.

<!-- PTO-READER-BLOCK: arch-fp19-rules-interactions role=rules-interactions -->
## Rules and interactions

Design point: the legal parameter domains are narrower than the carrier, because the scale and the activation parameter are applied as numeric factors; the B.FPATR parameter-word legality predicates apply `FP19ScaleLegal` or `FP19ActivationParameterLegal` to the FP19 field, and a parameter word that fails them is rejected before any effect.

`FP19ScaleLegal` accepts only `NumericValue_PositiveNormal`, so no negative value, zero, subnormal, infinity, or NaN can serve as a scale.

`FP19ActivationParameterLegal` accepts `NumericValue_PositiveZero` or `NumericValue_PositiveNormal`, so an activation parameter additionally allows positive zero but not negative zero.

<!-- PTO-READER-BLOCK: arch-fp19-boundaries role=boundaries -->
## Architectural boundaries

`FP32ToFP19` maps any `FP32` NaN to the fixed carrier `0111111111100000000`, and it carries a fraction overflow into the exponent so that a rounded mantissa of `0x400` becomes the next binade.

Design point: mapping every `FP32` NaN to one carrier makes the parameter value independent of which NaN payload the source carried, so a converted parameter has a single defined bit pattern.

There is no format descriptor and no decomposition function for `FP19`, so read the carrier helpers above directly: `FP19ValueClass` supplies the value class, `FP19ScaleLegal` and `FP19ActivationParameterLegal` supply the parameter domains, and `FP19FiniteValue` and `FP32ToFP19` interpret and produce a carrier.

<!-- PTO-READER-BLOCK: arch-fp19-example-usage role=example-usage -->
## Non-normative reading example

This example illustrates the current ASL owner and does not replace the normative operation.

Positive subnormal carriers are encodings `0x00001` through `0x003ff`, and negative subnormal carriers are encodings `0x40001` through `0x403ff`; the smallest positive subnormal is `1 * 2^-136` while the largest is `1023 * 2^-136`; the smallest positive normal is `1 * 2^-126`.

`FP19FiniteValue` asserts that the exponent field is not `255`, so an infinity or NaN carrier must be classified and rejected before the function is called.

// FP19 MUST use one sign bit, an eight-bit bias-127 exponent, and a ten-bit
// fraction. B.FPATR scales MUST be positive normal values; activation
// parameters MUST be positive zero or positive normal values. Subnormal and
// non-finite FP19 parameter carriers are illegal before architectural effects.
// NDF-END: PTO-FP19-PARAMETER-CARRIER-001

pure func FP19PowerOfTwo(exponent: integer {-136..127}) => real
begin
    var result: real = 1.0;
    if exponent > 0 then
        for step = 1 to exponent looplimit 127 do
            result = result * 2.0;
        end;
    elsif exponent < 0 then
        for step = 1 to -exponent looplimit 136 do
            result = result / 2.0;
        end;
    end;
    return result;
end;

pure func FP19ValueClass(value: bits(19)) => NumericValueClass
begin
    let exponent = value[17:10];
    let fraction = value[9:0];
    if exponent == Ones{8} then
        if fraction == Zeros{10} then
            if value[18] == '1' then
                return NumericValue_NegativeInfinity;
            else
                return NumericValue_PositiveInfinity;
            end;
        elsif fraction[9] == '1' then
            return NumericValue_QuietNaN;
        else
            return NumericValue_SignalingNaN;
        end;
    end;
    return NumericValueClassFromFiniteSign(
        value[18],
        exponent == Zeros{8} && fraction == Zeros{10},
        exponent == Zeros{8} && fraction != Zeros{10});
end;

pure func FP19FiniteValue(value: bits(19)) => real
begin
    let exponent = UInt(value[17:10]);
    let fraction = UInt(value[9:0]);
    assert exponent != 255;
    var magnitude: real = 0.0;
    if exponent == 0 then
        magnitude = Real(fraction) * FP19PowerOfTwo(-136);
    else
        magnitude = (1.0 + Real(fraction) / 1024.0) *
            FP19PowerOfTwo((exponent - 127) as integer {-126..127});
    end;
    if value[18] == '1' then return -magnitude; end;
    return magnitude;
end;

pure func FP19ScaleLegal(value: bits(19)) => boolean
begin
    return FP19ValueClass(value) == NumericValue_PositiveNormal;
end;

pure func FP19ActivationParameterLegal(value: bits(19)) => boolean
begin
    let value_class = FP19ValueClass(value);
    return value_class == NumericValue_PositiveZero ||
           value_class == NumericValue_PositiveNormal;
end;

pure func FP32ToFP19(value: Word) => bits(19)
begin
    let source = value[31:0];
    let source_class = ClassifyFP32(source);
    if NumericValueClassIsNaN(source_class) then
        return '0111111111100000000';
    end;
    var exponent: integer {0..256} = UInt(source[30:23]);
    var fraction: integer {0..1024} = UInt(source[22:13]);
    let discarded = UInt(source[12:0]);
    let halfway = 0x1000;
    if discarded > halfway ||
       (discarded == halfway && fraction MOD 2 == 1) then
        assert fraction <= 1023;
        fraction = (fraction + 1) as integer {0..1024};
        if fraction == 0x400 then
            fraction = 0;
            if exponent < 255 then
                exponent = (exponent + 1) as integer {0..256};
            end;
        end;
    end;
    var result = Zeros{19};
    assert exponent <= 255;
    assert fraction <= 1023;
    result[18] = source[31];
    result[17:10] = Zeros{8} + (exponent as integer {0..255});
    result[9:0] = Zeros{10} + (fraction as integer {0..1023});
    return result;
end;
