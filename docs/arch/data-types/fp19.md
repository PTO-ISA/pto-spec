## Purpose and scope

`FP19` is the 19-bit scalar and vector parameter carrier consumed by `B.FPATR`; this unit fixes its representation, legal parameter domains, finite interpretation, and conversion from `FP32`.

The carrier is defined here so scale and activation legality can be checked before an instruction produces architectural effects.

<!-- PTO-READER-BLOCK: arch-fp19-concepts-state role=concepts-state -->
## Concepts and visible state

- The layout is one sign bit, an eight-bit exponent with bias `127`, and a ten-bit fraction.
- `FP19ValueClass` classifies zero, subnormal, normal, infinity, quiet NaN, and signaling NaN using the 19-bit fields.
- `FP19FiniteValue` interprets finite carriers; `FP32ToFP19` narrows `FP32` by retaining the upper ten fraction bits and rounding discarded bits to nearest with ties to even.

<!-- PTO-READER-BLOCK: arch-fp19-rules-interactions role=rules-interactions -->
## Rules and interactions

`FP19ScaleLegal` accepts only `NumericValue_PositiveNormal`.

`FP19ActivationParameterLegal` accepts `NumericValue_PositiveZero` or `NumericValue_PositiveNormal`.

`FP32ToFP19` maps any `FP32` NaN to the fixed carrier `0111111111100000000` and handles fraction carry into the exponent.

<!-- PTO-READER-BLOCK: arch-fp19-boundaries role=boundaries -->
## Architectural boundaries

Subnormal, negative, infinity, and NaN carriers are outside the legal scale domain. Activation additionally permits positive zero, but no other extra class.

`FP19FiniteValue` asserts that the exponent is not `255`; non-finite inputs must be classified and rejected before calling it.

<!-- PTO-READER-BLOCK: arch-fp19-example-usage role=example-usage -->
## Non-normative reading example

A positive normal scale passes `FP19ScaleLegal`; the same bit pattern with the sign bit set does not, even though it still represents a finite value.

For an activation parameter, positive zero is legal while negative zero is not. The exact result follows the value-class check in the ASL owner.

// FP19 is the architectural scalar/vector parameter carrier used by B.FPATR.
// NDF-BEGIN: PTO-FP19-PARAMETER-CARRIER-001
// ndf: kind=contract level=L1 layer=architecture status=accepted
// FP19 MUST use one sign bit, an eight-bit bias-127 exponent, and a ten-bit
// fraction. B.FPATR scales MUST be positive normal values; activation
// parameters MUST be positive zero or positive normal values. Subnormal and
// non-finite FP19 parameter carriers are illegal before architectural effects.
// NDF-END: PTO-FP19-PARAMETER-CARRIER-001

pure func FP19PowerOfTwo(exponent: integer {-136..127}) => real
begin
    var result: real = 1.0;
    if exponent > 0 then
        for step = 1 to exponent looplimit 127 do
            result = result * 2.0;
        end;
    elsif exponent < 0 then
        for step = 1 to -exponent looplimit 136 do
            result = result / 2.0;
        end;
    end;
    return result;
end;

pure func FP19ValueClass(value: bits(19)) => NumericValueClass
begin
    let exponent = value[17:10];
    let fraction = value[9:0];
    if exponent == Ones{8} then
        if fraction == Zeros{10} then
            if value[18] == '1' then
                return NumericValue_NegativeInfinity;
            else
                return NumericValue_PositiveInfinity;
            end;
        elsif fraction[9] == '1' then
            return NumericValue_QuietNaN;
        else
            return NumericValue_SignalingNaN;
        end;
    end;
    return NumericValueClassFromFiniteSign(
        value[18],
        exponent == Zeros{8} && fraction == Zeros{10},
        exponent == Zeros{8} && fraction != Zeros{10});
end;

pure func FP19FiniteValue(value: bits(19)) => real
begin
    let exponent = UInt(value[17:10]);
    let fraction = UInt(value[9:0]);
    assert exponent != 255;
    var magnitude: real = 0.0;
    if exponent == 0 then
        magnitude = Real(fraction) * FP19PowerOfTwo(-136);
    else
        magnitude = (1.0 + Real(fraction) / 1024.0) *
            FP19PowerOfTwo((exponent - 127) as integer {-126..127});
    end;
    if value[18] == '1' then return -magnitude; end;
    return magnitude;
end;

pure func FP19ScaleLegal(value: bits(19)) => boolean
begin
    return FP19ValueClass(value) == NumericValue_PositiveNormal;
end;

pure func FP19ActivationParameterLegal(value: bits(19)) => boolean
begin
    let value_class = FP19ValueClass(value);
    return value_class == NumericValue_PositiveZero ||
           value_class == NumericValue_PositiveNormal;
end;

pure func FP32ToFP19(value: Word) => bits(19)
begin
    let source = value[31:0];
    let source_class = ClassifyFP32(source);
    if NumericValueClassIsNaN(source_class) then
        return '0111111111100000000';
    end;
    var exponent: integer {0..256} = UInt(source[30:23]);
    var fraction: integer {0..1024} = UInt(source[22:13]);
    let discarded = UInt(source[12:0]);
    let halfway = 0x1000;
    if discarded > halfway ||
       (discarded == halfway && fraction MOD 2 == 1) then
        assert fraction <= 1023;
        fraction = (fraction + 1) as integer {0..1024};
        if fraction == 0x400 then
            fraction = 0;
            if exponent < 255 then
                exponent = (exponent + 1) as integer {0..256};
            end;
        end;
    end;
    var result = Zeros{19};
    assert exponent <= 255;
    assert fraction <= 1023;
    result[18] = source[31];
    result[17:10] = Zeros{8} + (exponent as integer {0..255});
    result[9:0] = Zeros{10} + (fraction as integer {0..1023});
    return result;
end;
